# logitparserutils

这是 LogitOS 独立实现的解析基础库。它提供字节缓冲、容器、编码转换和分块输入流，
保留现有 `parserutils_*` 调用接口，内部不使用已移除的 libparserutils 实现。

**范围更正：** 第一版只覆盖浏览器调用，曾明确省略独立 codec 和 UTF-16 工具。
那不是完整替代。现在补齐本树原公开头中的 55 个函数入口（含 `peek_slow`），
并核对其输入、输出和状态变化。接口齐全不等于所有故障情形都已证明正确。

## 从哪里读起

| 文件 | 职责与关键约束 |
|---|---|
| `buffer.c` | 连续字节；插入自己的片段时先保存源数据；多段追加整体成功或不改长度 |
| `sequence.c`、`vector.c`、`stack.c` | 分页元素；扩容不会移动已有元素，弹出后的槽位可以复用 |
| `utf8.c`、`utf16.c` | Unicode 码点转换与前后移动；长度和位置都是字节数 |
| `names.c`、`registry.c` | 查编码名称、别名和 IANA 编号；认识名称不代表支持转换 |
| `charset.c` | 一个码点的编解码；单字节映射复用浏览器已有数据 |
| `codec.c`、`codec_input.c`、`codec_output.c` | 有状态转换；输入、输出各自保存不完整字符，互不覆盖 |
| `stream.c` | 保存待解码字节和已解码 UTF-8；处理编码探测、BOM、追加、插入、消费和 EOF |
| `window.c` | 旧窗口保留到其内容被消费，避免扩容、插入、压缩使借出的 peek 指针失效 |
| `errors.c` | 错误码与可读描述 |

## 调用时必须知道的事

codec 的 UCS-4 一侧固定为大端字节。无后缀的 UTF-16 codec 和 UTF-16 工具使用
主机字节序；显式 UTF-16LE/BE 按名称处理。UTF-16 工具的写入函数返回已写字节数，
UTF-8 写入函数则推进指针并减少剩余容量，两者不能混用。

输出空间不足时，codec 返回 NOMEM，保留一个完整输出字符。调用方使用更新后的
输入指针重试；即使输入已用完，也要用零长度输入排空输出。零长度输入不是 EOF，
不完整源字符会等待下一批字节。reset 丢弃两方向的暂存内容，保留错误处理模式。

默认宽松模式会替换非法字符；严格模式停在非法单元之前。TRANSLIT 使用文档允许的
宽松回退，没有伪装成语言转写器。Unicode 输出用 U+FFFD，单字节输出用问号。

输入流的 `append(NULL, 0)` 才表示 EOF；传入非空指针和零长度只表示这批没有数据。
`insert` 接收已经编码成 UTF-8 的内容。普通追加与插入都保留合法的 U+0000；
第一版把它改成 U+FFFD，现已纠正。CSS 专用预处理不属于通用流。

空栈 pop、空向量 remove_last 返回 INVALID。扩容失败不增加元素数量。
`buffer_randomise` 同时改变地址与对齐，`alloc` 是分配起点，`data` 才是有效内容。

## 数据来源与有意改变的行为

编解码实现是本项目代码，采用 GPL-3.0-or-later。字符映射复用浏览器原有
`encoding_tables.inc`，保留其数据来源。新增的 IANA 名称表是 CC0 注册数据，
共 258 条，生成文件记录下载地址和 SHA-256；`tools/gen_charset_registry.py`
从显式提供的 CSV 生成，正常构建不会联网。

原实现实际支持的 27 个编码名称均可创建 codec。ISO-8859-11 按当前 IANA 表
解析为 TIS-620 的编号 2259，不再返回旧库自定的 4014；4014 仍可反查名称。
历史上可查询的其他非 IANA 编号单独记录，不冒称标准编号。认识 UCS-2、UCS-4
等注册名称不等于实现了对应外部编码；不支持的名称返回 BADENCODING。

不复现旧实现的错误：拒绝代理项和超出 U+10FFFF 的码点，不生成过时的五、六字节
UTF-8；UTF-16 的高代理项使用正确位运算；未知错误名称不会返回虚假成功。
这里保留源码调用接口，不承诺旧二进制布局，输入流对象改为不透明对象。

实现依据为公开接口、调用方需求、标准数据及保留的基线二进制行为。
没有以旧库的 .c、私有编码表或生成器为模板；这不是法律意义上的 clean-room 认证。

验证记录见 [交付核对报告](../../../docs/reports/logit-css-support-2026-10-25.md)。
按用户要求没有新增测试文件；临时诊断结果不能替代长期回归覆盖。
