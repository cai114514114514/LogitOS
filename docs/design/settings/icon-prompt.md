# Settings application icon

Generated using the built-in imagegen tool. The original PNG with alpha is
packaged as `/icons/settings.png` and used by the Dock, Finder and Settings.

## Final prompt

Create one production-quality raster app icon for the Settings application of a new desktop operating system called LogitOS. This must be a real polished OS icon, not a UI screenshot or a flat SVG symbol. Square 1024x1024 canvas, fully transparent outside a rounded-square icon tile centered with a small 4 percent margin. The tile is rich cobalt blue ceramic glass with beautifully controlled bevels, subtle depth, gentle studio highlights. Center a substantial precision-machined brushed titanium gear, eight broad teeth, with a softly glowing blue circular center and a smaller inset adjustment dial. Orthographic front view, elegant tactile 3D material, impeccable crisp silhouette recognizable at 32 pixels, restrained premium industrial design, strong contrast, no tiny details. The gear occupies about 70 percent of the tile, tile occupies 92 percent of canvas. No text, no letters, no brand marks, no emoji, no SVG or vector outline style, no surrounding presentation or external shadow. Preserve real alpha transparency around the rounded corners. Deliver a single finished icon.
