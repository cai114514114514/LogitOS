## Final prompt

Use case: ui-mockup. Create one polished design reference image for the LogitOS Settings native desktop application. Landscape composition, a single front-facing 820 by 560 proportion window on a quiet pale neutral background. Native OS aesthetic, restrained blue accent, warm white content area, cool pale gray left sidebar, crisp dark readable typography, rounded grouped controls, generous spacing. Sidebar title Settings, subtitle LogitOS, navigation Appearance (selected), Desktop, Network, All settings. Main area title Appearance, subtitle Make this space your own. Two miniature light and dark desktop preview panels at top, each with a blue flowing wallpaper, miniature sidebar and window. Below: Dark appearance toggle; Accent colour with a row of blue teal purple orange pink circular swatches and Hue Saturation Lightness sliders; Reduce motion toggle. Bottom status Saved, and Revert / Apply buttons. No emoji, no Apple logo, no device frame, no fake graphs, no clutter. Precise high-fidelity product UI design reference, not a claim of a running screenshot.
