# M17 L2 — 集成 NetSurf LibCSS 实现记录

**Goal:** 用 NetSurf LibCSS 替换自写的 `net/css.c`,在 ring-3 browser 里做真正的
CSS 解析 / 选择器 / 级联 / 继承,渲染 example.com 与之前一致。

**结果:** ✅ 完成。LibCSS(libwapcaplet + libparserutils + libcss,共 319 个 .c)
编进 `browser.aex`(1.5MB),`user/css_engine.c` 把 LibCSS 适配成 css.h 接口
(`css_init`/`css_apply` → `struct cstyle`),layout/browser **零改动**。

## 关键发现

- **代码生成产物已 vendored**:`autogenerated_{computed,propget,propset}.h` /
  `autogenerated_destroy.inc` 已在仓库;只需补生成 ① 119 个简单属性解析器
  (`css_property_parser_gen` 从 `properties.gen` 每行生成一个 → `src/parse/properties/autogen/`)
  ② libparserutils 的 `aliases.inc`(`make-aliases.pl`)。两者已 vendored(L2a),
  `tools/gen_libcss.sh` 可复现。**无需构建期跑 perl/host-codegen。**
- **mini-libc 缺口极小**:补 `ctype.h` + `strings.h`(strcasecmp/strncasecmp)即可;
  其余外部符号(malloc/free/calloc/realloc/string/printf/abs/bsearch)mini-libc 全有。
- **编译开关**:`-DWITHOUT_ICONV_FILTER`(用内置 charset codec,免 iconv)+
  `-D_ALIGNED=`(NetSurf 的对齐宏,其 buildsystem 定义,我们置空)+ `-fcommon`。

## 架构(user/css_engine.c)

- **select handler**(~40 回调)驱动 LibCSS 读我们的 `struct node`(dom.h):
  node_name/classes/id、parent/sibling/ancestor、has_class/id/attribute*、is_root/link…
  关键:`#document` 合成根在 parent 回调里报告为 NULL,使 LibCSS 把 `<html>` 当
  根元素并解析绝对 font-size。
- **流程**:`css_stylesheet_create`+`append_data`(UA sheet + author CSS + 每节点
  inline `style=`)→ `css_select_style` 得 partial → `css_computed_style_compose`
  (parent 的 composed + child,用 css_unit_ctx)解析继承 + 相对单位 → `convert()`
  把 css_computed_* 读成 `struct cstyle`(display/color/bg/font/margin/padding/
  width/height/text-align/line-height/border/underline)。

## Bug 修复记录

- `css_computed_font_family(cs, NULL)` 解引用 NULL → 传有效指针。
- `<html>` 的 parent 是 `#document`(N_ELEM),被当真 parent → LibCSS 不当 root →
  font-size 不解析 → 全继承垃圾(clamp 到 minimum 6px)。修:parent 回调跳过 `#document`,
  且顶层节点 compose 传 parent=NULL(root 由 select_style 自身绝对化)。
