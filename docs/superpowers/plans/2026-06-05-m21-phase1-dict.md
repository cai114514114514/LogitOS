# M21 Phase 1 — AquaScript `dict` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a hash-table `dict` type to AquaScript (string/int keys) — literals `{}`/`{k:v}`, `d[k]` get/set, `.keys()/.values()/.has()/.get()/.remove()`, `k in d`, `for k in d`, `len(d)` — as the prerequisite for the self-hosted compiler's symbol tables.

**Architecture:** New `O_DICT` heap object: open-addressing hash table (linear probing + tombstones, grow at 0.75 load). Keys are strings (hashed via the existing `ObjStr.hash`) or 64-bit ints (splitmix finalizer). Three new opcodes (`OP_MAKE_DICT`, `OP_IN`, `OP_ITER`); `d[k]` reuses the existing `OP_INDEX_GET/SET`; methods reuse `OP_INVOKE`. Iteration/print are in **hash order, not insertion order** (fine for compiler symbol tables; tests avoid multi-key order dependence).

**Tech Stack:** C (freestanding-compatible: only malloc/free/realloc/memset/memcmp/snprintf, all in mini-libc and host libc). Core files: `src/apps/aqs/{aqs.h,object.c,lexer.c,lexer.h,compiler.c,vm.c,value.c}`. Tests: `tools/t/aqs_test.c` (host, `make test-aqs`) + `fsroot/aqs/dict.aqs` (on-Aqua, `make test-aqs-os`).

**Spec:** `docs/superpowers/specs/2026-06-05-m21-aquascript-self-hosting.md`

```c
/* ---- dict: open-addressing hash table, string|int keys (M21) ---- */
static uint32_t hash_int(int64_t v)
{
    uint64_t x = (uint64_t)v;                 /* splitmix64 finalizer */
    x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
    x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
    x =  x ^ (x >> 31);
    return (uint32_t)x;
}
static uint32_t key_hash(Value k) { return IS_STR(k) ? AS_STR(k)->hash : hash_int(AS_INT(k)); }
static int key_match(DictEntry *e, Value k)
{
    if (IS_STR(k)) return e->kind == AQS_DK_STR && e->kstr->hash == AS_STR(k)->hash
                          && e->kstr->len == AS_STR(k)->len
                          && memcmp(e->kstr->chars, AS_STR(k)->chars, (size_t)e->kstr->len) == 0;
    return e->kind == AQS_DK_INT && e->kint == AS_INT(k);
}
/* Return the slot holding `k`, or the slot to insert into (first tombstone, else
 * the terminating empty slot). cap must be > 0 and a power of two. */
static DictEntry *find_entry(DictEntry *es, int cap, Value k)
{
    uint32_t mask = (uint32_t)(cap - 1);
    uint32_t i = key_hash(k) & mask;
    DictEntry *tomb = NULL;
    for (;;) {
        DictEntry *e = &es[i];
        if (e->kind == AQS_DK_EMPTY) return tomb ? tomb : e;
        if (e->kind == AQS_DK_TOMB) { if (!tomb) tomb = e; }
        else if (key_match(e, k)) return e;
        i = (i + 1) & mask;
    }
}
ObjDict *aqs_dict_new(void)
{
    ObjDict *d = (ObjDict *)alloc_obj(sizeof(ObjDict), O_DICT);
    d->entries = NULL; d->live = d->used = d->cap = 0;
    return d;
}
static void dict_grow(ObjDict *d)
{
    int newcap = d->cap < 8 ? 8 : d->cap * 2;
    DictEntry *ne = (DictEntry *)malloc((size_t)newcap * sizeof(DictEntry));
    memset(ne, 0, (size_t)newcap * sizeof(DictEntry));        /* AQS_DK_EMPTY == 0 */
    int live = 0;
    for (int i = 0; i < d->cap; i++) {
        DictEntry *e = &d->entries[i];
        if (e->kind != AQS_DK_STR && e->kind != AQS_DK_INT) continue;   /* drop tombstones */
        Value k = e->kind == AQS_DK_STR ? OBJ_VAL(e->kstr) : INT_VAL(e->kint);
        *find_entry(ne, newcap, k) = *e;
        live++;
    }
    free(d->entries);
    d->entries = ne; d->cap = newcap; d->used = live; d->live = live;
}
int aqs_dict_set(ObjDict *d, Value key, Value val)
{
    if (!IS_STR(key) && !IS_INT(key)) return 0;
    /* grow at 0.75 load; cap is a power of two so cap>>2 == cap/4 exactly, and the
     * subtraction form can't overflow int the way (used+1)*4 >= cap*3 would. cap 0 -> grow to 8. */
    if (d->used + 1 >= d->cap - (d->cap >> 2)) dict_grow(d);
    DictEntry *e = find_entry(d->entries, d->cap, key);
    int existing = (e->kind == AQS_DK_STR || e->kind == AQS_DK_INT);
    if (!existing) {
        if (e->kind == AQS_DK_EMPTY) d->used++;               /* tombstone reuse doesn't add to load */
        d->live++;
        if (IS_STR(key)) { e->kind = AQS_DK_STR; e->kstr = AS_STR(key); }
        else             { e->kind = AQS_DK_INT; e->kint = AS_INT(key); }
    }
    e->val = val;
    return 1;
}
int aqs_dict_get(ObjDict *d, Value key, Value *out)
{
    if (d->cap == 0 || (!IS_STR(key) && !IS_INT(key))) return 0;
    DictEntry *e = find_entry(d->entries, d->cap, key);
    if (e->kind != AQS_DK_STR && e->kind != AQS_DK_INT) return 0;
    *out = e->val; return 1;
}
int aqs_dict_has(ObjDict *d, Value key) { Value tmp; return aqs_dict_get(d, key, &tmp); }
int aqs_dict_remove(ObjDict *d, Value key)
{
    if (d->cap == 0 || (!IS_STR(key) && !IS_INT(key))) return 0;
    DictEntry *e = find_entry(d->entries, d->cap, key);
    if (e->kind != AQS_DK_STR && e->kind != AQS_DK_INT) return 0;
    e->kind = AQS_DK_TOMB; d->live--;                         /* used unchanged: slot still probed-through */
    return 1;
}
ObjList *aqs_dict_keys(ObjDict *d)
{
    ObjList *l = aqs_list_new();
    for (int i = 0; i < d->cap; i++) {
        DictEntry *e = &d->entries[i];
        if (e->kind == AQS_DK_STR)      aqs_list_push(l, OBJ_VAL(e->kstr));
        else if (e->kind == AQS_DK_INT) aqs_list_push(l, INT_VAL(e->kint));
    }
    return l;
}
ObjList *aqs_dict_values(ObjDict *d)
{
    ObjList *l = aqs_list_new();
    for (int i = 0; i < d->cap; i++) {
        DictEntry *e = &d->entries[i];
        if (e->kind == AQS_DK_STR || e->kind == AQS_DK_INT) aqs_list_push(l, e->val);
    }
    return l;
}
```

```c
static void dict_literal(void)   /* prefix for '{' : a dict display */
{
    int n = 0;
    if (!check(T_RBRACE)) {
        do {
            expression();                                  /* key */
            consume(T_COLON, "expected ':' between dict key and value");
            expression();                                  /* value */
            n++;
        } while (match(T_COMMA));
    }
    consume(T_RBRACE, "expected '}' after dict entries");
    if (n > 255) { error("dict literal too large"); return; }
    emit2(OP_MAKE_DICT, (uint8_t)n);
}
```

## Notes for the implementer
- **Hash order, not insertion order.** `print(dict)`, `.keys()`, `.values()`, and `for k in d` yield entries in hash-table-slot order. That's why every multi-key test sums values or counts rather than asserting a printed order; only single-entry dicts assert exact print output. Don't "fix" this by sorting — it's intended for phase 1.
- **Tombstones, not backward-shift** (a deliberate deviation from the spec's suggestion): clox-style tombstones are simpler and provably correct; tombstone buildup only matters under heavy delete churn, which compiler symbol tables don't do. `dict_grow` drops tombstones on every resize.
- **Opcodes are appended** to the `OpCode` enum (never renumber) so existing in-memory bytecode is unaffected.
- **`AQS_DK_*` kind constants** live in `aqs.h` so both `object.c` and `value.c` use them (no magic numbers).
- Each task is an independent commit; run `make test-aqs` after every task.
