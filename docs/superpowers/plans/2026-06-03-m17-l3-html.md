# M17 L3 — 加深 HTML 解析(net/dom.c)实现记录

**Goal:** 让自写的 HTML 解析器更接近 HTML5,喂饱 LibCSS 选择器与真实页面
(列表、表格、实体)。

**结果:** ✅ 完成。`net/dom.c` 增强 + `tools/t/dom_test.c` 扩展。

## 增强项

1. **具名实体表**:从 6 个(amp/lt/gt/quot/apos/nbsp)扩展到 ~60 个常用实体
   (mdash/ndash/copy/reg/trade/hellip/times/divide/quotes/euro/pound/带重音拉丁
   字母等),decode 成正确 codepoint → UTF-8。数字实体(`&#169;` / `&#x2014;`)本就支持。
2. **隐式 `<tbody>`**:`<tr>` 直接位于 `<table>` 下时自动插入 `<tbody>`(HTML5),
   使 `tbody` / `table > tbody > tr` 选择器与表格结构正确。
3. **可选结束标签自动闭合**(HTML5 optional end tags):新的 `<li>/<td>/<th>/<tr>/
   <dd>/<dt>/<option>/<p>` 自动闭合仍打开的同级,避免 `<ul><li>A<li>B` 被错误嵌套。
4. 选择器供给:class/id/属性早已由 `dom_attr` + L2 的 css_select_handler 支持
   (`.class` / `#id` / `[attr=val]` 在 L2 已验证)。

## 验证

- host `dom_test`:原有(标签/属性/void/`&amp;`)+ 新增 ——
  `&mdash;→U+2014`、`&copy;→U+00A9`、`&rsquo;→U+2019`、隐式 tbody 嵌套、
  `<ul><li>A<li>B<li>C` → 3 个 li 兄弟。全 PASS。
- 回归:`layout_test` / `page_test` / `css_engine_test`(均经 LibCSS)全 PASS。
- QEMU:example.com 渲染无回归(dom.c 改动不影响无表格/实体的页面)。

注:真正的表格**网格布局**属 net/layout.c 的范畴(当前按 block 流堆叠),不在 L3。
