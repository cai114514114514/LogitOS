# M22.2 — AetherScript mark-sweep GC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a non-moving mark-sweep garbage collector so AetherScript reclaims unreachable objects during execution (instead of only freeing everything at program exit).

**Architecture:** Mark-sweep over the existing `g_objs` linked list. `Obj` gets a `marked` bit. Marking uses a gray-stack worklist (no recursion): mark roots (value stack, frames' fn+closure, open-upvalue list, builtins, modules) → blacken each gray object (mark its references) → sweep (free unmarked, unlink). Trigger is a live-object-count threshold (×2 grow), checked in `alloc_obj` *before* allocating. GC is disabled during compilation and during `as_run` setup (where new objects aren't yet rooted). A `-DAS_GC_STRESS` build collects before every allocation to shake out missing roots.

**Tech Stack:** C (freestanding-compatible). Files: `src/apps/as/{as.h,object.c,vm.c,compiler.c}`, `tools/t/as_test.c`, `Makefile`, `scripts/run-as-test.sh`, `fsroot/as/gc.as`.

**Spec:** `docs/superpowers/specs/2026-06-06-m22-gc.md`

static void free_object(Obj *o)

    case O_STR:  free(((ObjStr *)o)->chars); break;

- [ ] **Step 2: object.c — add mark + blacken + gc_collect immediately before `free_object`'s definition**

```c
void gc_mark_obj(Obj *o)
{
    if (o == NULL || o->marked) return;
    o->marked = 1;
    if (gray_count + 1 > gray_cap) {
        gray_cap = gray_cap < 16 ? 16 : gray_cap * 2;
        gray = (Obj **)realloc(gray, (size_t)gray_cap * sizeof(Obj *));
    }
    gray[gray_count++] = o;
}
void gc_mark_value(Value v) { if (IS_OBJ(v)) gc_mark_obj(AS_OBJ(v)); }

/* Mark everything an already-gray object references. */
static void blacken(Obj *o)
{
    switch (o->type) {
    case O_STR: case O_NATIVE: case O_PTR: break;   /* no object references */
    case O_UPVALUE: gc_mark_value(((ObjUpvalue *)o)->closed); break;
    case O_FN: {
        ObjFn *fn = (ObjFn *)o;
        if (fn->name) gc_mark_obj((Obj *)fn->name);
        for (int i = 0; i < fn->kcount; i++) gc_mark_value(fn->consts[i]);
        break;
    }
    case O_CLOSURE: {
        ObjClosure *c = (ObjClosure *)o;
        gc_mark_obj((Obj *)c->fn);
        for (int i = 0; i < c->upvalue_count; i++) gc_mark_obj((Obj *)c->upvalues[i]);
        break;
    }
    case O_LIST: {
        ObjList *l = (ObjList *)o;
        for (int i = 0; i < l->count; i++) gc_mark_value(l->items[i]);
        break;
    }
    case O_DICT: {
        ObjDict *d = (ObjDict *)o;
        for (int i = 0; i < d->cap; i++) {
            DictEntry *e = &d->entries[i];
            if (e->kind == AS_DK_STR) gc_mark_obj((Obj *)e->kstr);
            if (e->kind == AS_DK_STR || e->kind == AS_DK_INT) gc_mark_value(e->val);
        }
        break;
    }
    case O_MODULE: {
        ObjModule *m = (ObjModule *)o;
        gc_mark_obj((Obj *)m->name);
        for (int i = 0; i < m->count; i++) { gc_mark_obj((Obj *)m->vars[i].name); gc_mark_value(m->vars[i].val); }
        break;
    }
    }
}

void gc_collect(void)
{
    gray_count = 0;
    as_vm_mark_roots();                              /* mark + gray the roots (vm.c) */
    while (gray_count > 0) blacken(gray[--gray_count]);   /* trace to fixpoint */
    Obj **link = &g_objs;                             /* sweep */
    while (*link) {
        Obj *o = *link;
        if (o->marked) { o->marked = 0; link = &o->next; }
        else { *link = o->next; free_object(o); }
    }
    next_gc = live_objects * 2;
    if (next_gc < 1024) next_gc = 1024;
}
```

## Notes for the implementer
- **Why GC triggers BEFORE allocating** (top of `alloc_obj`): the new object doesn't exist yet, so it can't be wrongly collected; and the inputs to whatever operation is allocating are already rooted (on the value stack / in globals).
- **Why GC is disabled during compile + run-setup**: those phases create objects that aren't yet reachable from any VM root. The disable is a re-entrant counter (import can nest compiles).
- **The stress build (Task 3) is the real validator.** Mark-sweep correctness lives or dies on the root set being complete. `-DAS_GC_STRESS` collecting before every allocation turns any missing root into an immediate, reproducible failure over the whole suite. Treat a stress failure as "a root is missing," not "GC is flaky."
- **No string interning** in AetherScript, so there's no weak string-table to fix up during sweep (unlike clox) — sweep is just "free unmarked, unlink."
- **Shared upvalues**: one `ObjUpvalue` can sit in several closures' `upvalues[]` arrays; marking is idempotent and sweep frees each object once via the `g_objs` chain (never through a closure's array), so sharing is handled naturally.
- Each task is an independent commit; run `make test-as` after each, and `make test-as-gcstress` from Task 3 on.
