# M17 L4 — JavaScript ↔ DOM 绑定实现记录

**Goal:** QuickJS 里建 document / Element 对象,JS 可读写实时 DOM
(getElementById / querySelector / textContent / innerHTML / getAttribute /
setAttribute),改 DOM 后浏览器重排重绘。

**结果:** ✅ 完成。`user/js_dom.c` 提供绑定;`user/browser.c` 在 JS 改 DOM 后
re-style + re-layout + repaint。

## 为什么现在可行

L1 把整条管线(含 DOM)搬进 ring-3 browser,QuickJS 也在同一 ring-3 地址空间,
所以 JS 能直接操作 `struct node`(net/dom.c)——无需跨地址空间 marshalling。

## 实现(user/js_dom.c)

- **Element class**(QuickJS class + opaque = `struct node*`),`wrap(node)` 包装。
- **document**:`getElementById(id)`、`querySelector(sel)`(支持 `#id`/`.class`/`tag`)、`body`。
- **Element**:`textContent`(get 递归收集文本 / set 替换子节点为一个文本节点)、
  `innerHTML`(get)、`tagName`、`id`、`getAttribute(n)`、`setAttribute(n,v)`。
- **dirty flag**:textContent/setAttribute 写操作置位;`run_js` 返回后 browser 查
  `js_dom_dirty()`,若改动则 `css_apply` + `layout_page` + `redraw`(重排重绘)。
- 内存:set_text 用 `dom_free` 释放旧子树,malloc 新文本节点;setAttribute 必要时
  realloc 属性数组——与 dom.c 的所有权一致(dom_free 统一回收)。

## 验证

- host `js_dom_test`(quickjs+dom+js_dom,native,`-DCONFIG_BIGNUM` 补 host libbf):
  getElementById/querySelector/textContent get+set/setAttribute+getAttribute/
  dirty/缺失返回 null,全 PASS。
- **端到端 QEMU**:host `python -m http.server` 提供一个带 `<script>` 的页面,
  浏览器访问 `http://10.0.2.2:8099/`,`<script>` 用 getElementById/querySelector
  改三处 textContent;截图确认页面显示**改写后**的文本(标题/段落/note),CSS
  样式正确套用到新文本,状态栏 "loaded (script updated the page)",无 fault。
