### STAGE B — f-strings (+ depends on str() from Stage A)

B1. lexer.h — add `T_FSTR` to TokType immediately before `T_EOF` (line 20).

B2. lexer.c — f-prefix intercept in the identifier branch (lexer.c:99-102). After `int len = (int)(p - s);` and BEFORE `push(&b, keyword(s,len), ...)`:
```
if (len == 1 && (s[0]=='f'||s[0]=='F') && (*p=='"'||*p=='\'')) {
    char q = *p++; const char *cs = p; int depth = 0;
    while (*p && (*p != q || depth > 0)) {
        char ch = *p;
        if (ch=='\\' && p[1]) { p += 2; continue; }
        if (depth == 0) {
            if (ch=='{' && p[1]=='{') { p += 2; continue; }   /* literal {{ */
            if (ch=='}' && p[1]=='}') { p += 2; continue; }   /* literal }} */
            if (ch=='{') { depth = 1; p++; continue; }        /* enter hole */
            p++; continue;
        }
        /* inside a hole: track nesting + skip string literals */
        if (ch=='\'' || ch=='"') { char hq=ch; p++; while (*p && *p!=hq){ if(*p=='\\'&&p[1]) p+=2; else p++; } if(*p) p++; continue; }
        if (ch=='{'||ch=='('||ch=='[') depth++;
        else if (ch=='}'||ch==')'||ch==']') depth--;   /* the hole-closing } brings depth to 0 */
        p++;
    }
    if (*p != q) { snprintf(as_err, sizeof as_err, "unterminated string (line %d)", line); err = 1; break; }
    push(&b, T_FSTR, cs, (int)(p - cs), line);
    p++;   /* closing quote */
} else {
    push(&b, keyword(s, len), s, len, line);
}
```
(Note: the depth bookkeeping makes the hole-closing `}` decrement depth from 1 to 0, after which the next loop iteration sees `*p==q` and exits — correct.)

Implement `static void compile_comprehension(int forP)`:
```
begin_scope();
emit2(OP_MAKE_LIST, 0);
int acc = add_local("", 0);
int elem_P = P;                 /* element expr starts here */
P = forP;                       /* jump to 'for' */
advance();                      /* consume T_FOR */
consume(T_IDENT, "expected a loop variable"); Token var = tk_prev();
consume(T_IN, "expected 'in'");

emit2(OP_GET_LOCAL, idx); emit2(OP_GET_LOCAL, seq); emit(OP_LEN); emit(OP_LT);
int exit_j = emitJump(OP_JUMP_IF_FALSE); emit(OP_POP);
emit2(OP_GET_LOCAL, seq); emit2(OP_GET_LOCAL, idx); emit(OP_INDEX_GET);
emit2(OP_SET_LOCAL, vslot); emit(OP_POP);
```

IMPORTANT acc-survival detail: end_scope (compiler.c:124-132) pops every local at the current depth, INCLUDING acc, which would also emit OP_POP and drop the result we just loaded. Mirror for_statement's pattern: do NOT rely on end_scope to leave the result. Instead, the result value pushed by `GET_LOCAL acc` sits ABOVE the locals; end_scope emits OP_POP for each of the 4 hidden locals (acc/seq/idx/var) which would pop the result + 3 locals incorrectly. RESOLUTION: load the result into a temp by leaving `GET_LOCAL acc` AFTER end_scope is conceptually wrong. Use for_statement's actual approach: it does `end_scope()` which pops idx/seq/var, and leaves nothing — but here we must yield a value. So instead: before end_scope, `emit2(OP_GET_LOCAL, acc)` to copy the list to the top; end_scope pops the 4 named locals (acc, seq, idx, var) leaving the copy on top. That is exactly the sequence above (GET_LOCAL acc BEFORE end_scope) — verify the copy is above all 4 locals so the 4 OP_POPs from end_scope remove the locals and leave the copy. (The copy is pushed last, so it is on top; end_scope's 4 pops remove the 4 locals beneath it — CORRECT, identical reasoning to how a block's trailing expression survives.) Keep this exact ordering; add a comment.

### STAGE D — Multiple assignment / unpack (assignment() extension)

D1. compiler.c — assignment() (lines 395-432). After `Token name = tk_prev();` (line 398) and BEFORE the `if (match(T_DOT))` (line 399), insert:
```
if (check(T_COMMA)) {
    Token targets[64]; int nt = 0; targets[nt++] = name;
    while (match(T_COMMA)) { consume(T_IDENT, "expected a name in multiple assignment"); targets[nt++] = tk_prev(); if (nt >= 64) { error("too many assignment targets"); return; } }
    consume(T_ASSIGN, "expected '=' in multiple assignment");
    expression();                                  /* first RHS */
    if (check(T_COMMA)) {                           /* tuple form: e1, e2, ... */
        int nv = 1; while (match(T_COMMA)) { expression(); nv++; }
        if (nv != nt) { error("assignment count mismatch"); return; }
        for (int i = nt - 1; i >= 0; i--) store_name(targets[i]);   /* values v0..v_{nt-1} on stack, top=v_{nt-1}; store last->first */
    } else {                                        /* list form: a,b = <list> */
        begin_scope();
        int tmp = add_local("", 0);                /* RHS list becomes this slot (value already on stack) */
        for (int i = 0; i < nt; i++) { emit2(OP_GET_LOCAL, (uint8_t)tmp); emitConst(INT_VAL(i)); emit(OP_INDEX_GET); store_name(targets[i]); }
        end_scope();                               /* pops tmp */
    }
    return;
}
```
Notes: store_name (compiler.c:371-379) for a brand-new top-level name emits OP_DEF_GLOBAL (consumes the stack top); for an existing local emits SET_LOCAL+POP. The tuple-form reverse store order is REQUIRED so the top-of-stack value maps to the last target. Targets are bare identifiers only (the `.field`/`[i]` forms remain single-target via the existing code path, untouched). The list-form `OP_INDEX_GET` bounds-checks (vm.c:547-548), giving a runtime error for too-few values.
