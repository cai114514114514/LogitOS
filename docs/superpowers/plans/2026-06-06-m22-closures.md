# M22.1 — AetherScript Closures + lambda Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give AetherScript real closures — nested `def`/lambda that capture enclosing variables by reference (counter closures work) — using the clox upvalue model, plus `lambda` anonymous functions.

**Architecture:** Two new heap objects: `ObjUpvalue` (points at a live stack slot while open; owns a `closed` copy once the slot dies) and `ObjClosure` (an `ObjFn` + its captured upvalues). **Every `def`/lambda compiles to an `ObjClosure`** (0-upvalue ones too); the top-level script stays a bare `ObjFn` (frame.closure = NULL). The compiler resolves captured names into per-function upvalue lists (`resolve_upvalue`, recursive for multi-level capture); the VM captures/dedups open upvalues in a sorted list and closes them on scope exit / return. No GC yet — closures/upvalues live in the arena (M22.2 adds GC and makes them the first traced escapees).

**Tech Stack:** C (freestanding-compatible: malloc/free/memcmp/memset/snprintf only). Files: `src/apps/as/{as.h,object.c,vm.c,compiler.c,lexer.c,lexer.h,value.c}`. Tests: `tools/t/as_test.c` (host, `make test-as`) + `fsroot/as/closure.as` (on-Aether, `make test-as-os`).

**Spec:** `docs/superpowers/specs/2026-06-06-m22-closures.md`

```c
/* Find or create the upvalue capturing stack slot `slot`; shared so two closures
 * over the same variable see each other's writes. The list is sorted by address
 * descending (top of stack first). */
static ObjUpvalue *capture_upvalue(Value *slot)
{
    ObjUpvalue *prev = NULL, *cur = open_upvalues;
    while (cur && cur->location > slot) { prev = cur; cur = cur->next; }
    if (cur && cur->location == slot) return cur;
    ObjUpvalue *uv = as_upvalue_new(slot);
    uv->next = cur;
    if (prev) prev->next = uv; else open_upvalues = uv;
    return uv;
}
/* Close (move off the stack into their own storage) every open upvalue at or above
 * `last`. Called when a scope's captured locals die and on function return. */
static void close_upvalues(Value *last)
{
    while (open_upvalues && open_upvalues->location >= last) {
        ObjUpvalue *uv = open_upvalues;
        uv->closed = *uv->location;
        uv->location = &uv->closed;
        open_upvalues = uv->next;
    }
}
```

```c
static int add_upvalue(Compiler *c, uint8_t index, uint8_t is_local)
{
    int n = c->fn->upvalue_count;
    for (int i = 0; i < n; i++)
        if (c->upvalues[i].index == index && c->upvalues[i].is_local == is_local) return i;
    if (n == 256) { error("too many captured variables in one function"); return 0; }
    c->upvalues[n].is_local = is_local;
    c->upvalues[n].index = index;
    return c->fn->upvalue_count++;
}
/* Resolve `name` as an upvalue of compiler `c`: an enclosing local (is_local=1)
 * or, recursively, an enclosing upvalue (is_local=0). Returns the upvalue index
 * in `c`, or -1 if not found in any enclosing function. */
static int resolve_upvalue(Compiler *c, const char *name, int len)
{
    if (c->enclosing == NULL) return -1;
    int local = resolve_local(c->enclosing, name, len);
    if (local >= 0) {
        c->enclosing->locals[local].is_captured = 1;
        return add_upvalue(c, (uint8_t)local, 1);
    }
    int up = resolve_upvalue(c->enclosing, name, len);
    if (up >= 0) return add_upvalue(c, (uint8_t)up, 0);
    return -1;
}
```

```c
/* Compile a function body into a nested ObjFn and emit OP_CLOSURE (+ upvalue
 * operand bytes) into the enclosing fn, leaving the closure on the stack. For a
 * `def` (is_lambda=0) params are in (...) and the body is a block; for a lambda
 * (is_lambda=1) params run to ':' and the body is one expression. */
static void compile_function(const char *name, int namelen, int is_lambda)
{
    Compiler comp;
    comp.enclosing = current;
    comp.fn = as_fn_new();
    comp.fn->name = as_str_copy(name, namelen);
    comp.fn->module = g_module;
    comp.local_count = 0;
    comp.scope_depth = 0;
    comp.locals[0].name = ""; comp.locals[0].len = 0; comp.locals[0].depth = 0; comp.locals[0].is_captured = 0;
    comp.local_count = 1;                          /* slot 0 = callee */
    current = &comp;

    if (is_lambda) {
        if (!check(T_COLON)) {
            do {
                consume(T_IDENT, "expected a parameter name");
                comp.fn->arity++;
                add_local(tk_prev().start, tk_prev().len);
            } while (match(T_COMMA));
        }
        consume(T_COLON, "expected ':' after lambda parameters");
        expression();                              /* single-expression body */
        emit(OP_RET);
    } else {
        consume(T_LPAREN, "expected '(' after the function name");
        if (!check(T_RPAREN)) {
            do {
                consume(T_IDENT, "expected a parameter name");
                comp.fn->arity++;
                add_local(tk_prev().start, tk_prev().len);
            } while (match(T_COMMA));
        }
        consume(T_RPAREN, "expected ')' after parameters");
        consume(T_COLON, "expected ':' after the parameter list");
        block();
        emit(OP_NIL); emit(OP_RET);                /* implicit `return nil` */
    }

    ObjFn *fn = comp.fn;
    current = comp.enclosing;
    emit2(OP_CLOSURE, (uint8_t)makeConst(OBJ_VAL(fn)));
    for (int i = 0; i < fn->upvalue_count; i++) { emit(comp.upvalues[i].is_local); emit(comp.upvalues[i].index); }
}

static void fun_declaration(void)
{
    consume(T_IDENT, "expected a function name");
    Token name = tk_prev();
    compile_function(name.start, name.len, 0);     /* leaves the closure on the stack */
    if (current->enclosing == NULL) emit2(OP_DEF_GLOBAL, (uint8_t)identConst(name.start, name.len));
    else store_name(name);
}

static void lambda_(void)   /* prefix for 'lambda' : an anonymous closure expression */
{
    compile_function("<lambda>", 8, 1);
}
```

## Notes for the implementer
- **`frame->fn` stays valid in every frame** (= `closure->fn` for closures, the script for the top-level), so `READ_CONST`/`resolve_global` (which use `frame->fn`) are untouched. Only upvalue ops use `frame->closure` — and they're only emitted inside functions that have a non-NULL closure, never at top level.
- **Capture-on-write is intended:** assigning a name that lives in an enclosing function emits `SET_UPVALUE` (mutates the outer variable), so counter closures work. A brand-new name in a function still becomes a local. This means you can't shadow an outer variable by assignment inside an inner function — that's the documented trade-off (no `nonlocal`).
- **`open_upvalues` ordering matters:** the list is sorted by stack address descending; `capture_upvalue` walks while `cur->location > slot` and dedups on `==`, `close_upvalues` peels from the head while `location >= last`. Don't reorder these comparisons.
- **No GC yet:** closures/upvalues are arena objects freed by `as_free_objects`. Task 1's free case frees only the `upvalues` *array* — the upvalue objects and captured values are separate arena objects. M22.2 (GC) will trace `open_upvalues` + closures on the stack as roots.
- Opcodes are appended to the enum (never renumbered). Each task is an independent commit; run `make test-as` after each.
