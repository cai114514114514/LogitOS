# M22.3 — AetherScript Classes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give AetherScript single-inheritance classes (clox-lineage, Python-ish indentation) with explicit `self`: `class Name:` / `class Name(Super):`, `def method(self, ...)`, `Name(args)` construction with an `init` initializer, `inst.field` get/set, bound methods, method override via copy-down inheritance, and `super.method(self, ...)`.

**Architecture:** Three new heap objects — `ObjClass` (name + super pointer + a methods `ObjDict`), `ObjInstance` (klass + fields `ObjDict`), `ObjBoundMethod` (receiver + `ObjClosure`). Methods are **ordinary closures** taking explicit `self` (no clox "this"/this-upvalue machinery). Method lookup is **copy-down** (clox): `OP_INHERIT` copies a superclass's methods into the subclass methods dict, so normal lookup hits one dict; the `super` pointer is kept only for `super.method`. New opcodes (appended): `OP_CLASS, OP_INHERIT, OP_METHOD, OP_GET_PROPERTY, OP_SET_PROPERTY, OP_GET_SUPER`. `OP_INVOKE` is extended for instance methods; `OP_GET_ATTR` is retired (its module-attr role folds into `OP_GET_PROPERTY`, the enum value stays for numbering). GC tracing for all three types lands in Task 1 so later tasks are stress-safe.

**Tech Stack:** C (freestanding-compatible: malloc/free/memcmp/memset/snprintf only). Files: `src/apps/as/{as.h,object.c,vm.c,compiler.c,lexer.c,lexer.h,value.c}`. Tests: `tools/t/as_test.c` (host, `make test-as` + `make test-as-gcstress`) + `fsroot/as/classes.as` (on-Aether, `make test-as-os`).

**Spec:** `docs/superpowers/specs/2026-06-06-m22-classes.md`

**House rules:** opcodes are APPENDED to the enum (never renumber existing ones); every new heap object type is traced in `blacken`, freed in `free_object`, and rooted if it adds VM-global object state (these three don't — they live in module/local slots already covered by `as_vm_mark_roots`); a constructor doing ≥2 `alloc_obj` before the object is rooted wraps them in `as_gc_push_disable()/as_gc_pop_disable()`; a VM opcode holding a fresh object across a later `alloc_obj` pushes it on the value stack first (the `OP_CLOSURE` pattern). Each task is one commit ending with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

```c
/* M22.3 classes. A class's method table is an ObjDict (name(str) -> ObjClosure);
 * an instance's fields are an ObjDict (name(str) -> Value) -- reusing ObjDict keeps
 * GC tracing DRY. `super` is kept only for super.method; method LOOKUP is copy-down
 * (OP_INHERIT copies the parent's methods into the child), so normal lookup is one
 * dict. Methods are ordinary closures taking an explicit `self` first parameter. */
typedef struct ObjClass {
    Obj obj;
    ObjStr *name;
    struct ObjClass *super;     /* parent class, or NULL */
    ObjDict *methods;           /* name(str) -> ObjClosure */
} ObjClass;
typedef struct {
    Obj obj;
    ObjClass *klass;
    ObjDict *fields;            /* name(str) -> Value */
} ObjInstance;
typedef struct {
    Obj obj;
    Value receiver;             /* the bound self (an instance) */
    ObjClosure *method;
} ObjBoundMethod;
```

- [ ] **Step 7: compiler.c — add class_declaration after fun_declaration**

Immediately after the `fun_declaration` function's closing `}`, insert:
```c
/* class NAME [ '(' SUPER ')' ] ':' NEWLINE INDENT (def method)+ DEDENT
 * Emits OP_CLASS (build empty class) -> bind the name -> optional OP_INHERIT
 * (copy-down super's methods) -> per-method: push class, compile the method body
 * as a closure, OP_METHOD to register it, pop the leftover class copy. */
static void class_declaration(void)
{
    consume(T_IDENT, "expected a class name");
    Token name = tk_prev();
    int namek = identConst(name.start, name.len);

    emit2(OP_CLASS, (uint8_t)namek);                 /* -> new empty class on the stack */
    /* Bind the name immediately so methods can reference the class (and so `super`'s
     * OP_GET_GLOBAL <classname> resolves at method-run time). */
    if (current->enclosing == NULL) { emit2(OP_DEF_GLOBAL, (uint8_t)namek); }
    else { add_local(name.start, name.len); }        /* nested: the class lives in this local slot */

    struct { const char *name; int namelen; int has_super; int active; } saved = current_class;
    current_class.name = name.start; current_class.namelen = name.len;
    current_class.has_super = 0; current_class.active = 1;

    int has_super = 0;
    if (match(T_LPAREN)) {
        consume(T_IDENT, "expected a superclass name");
        Token sup = tk_prev();
        if (sup.len == name.len && memcmp(sup.start, name.start, name.len) == 0)
            error("a class cannot inherit from itself");
        /* push superclass, then the class, then OP_INHERIT (copy-down) leaving the class. */
        named_variable(sup);                         /* read the superclass value */
        named_variable(name);                        /* read the class we just bound */
        emit(OP_INHERIT);                            /* [.. super class] -> [.. class] */
        consume(T_RPAREN, "expected ')' after the superclass name");
        has_super = 1; current_class.has_super = 1;
    } else {
        named_variable(name);                        /* leave the class on the stack for methods */
    }

    consume(T_COLON, "expected ':' after the class header");
    consume(T_NEWLINE, "expected a newline before the class body");
    consume(T_INDENT, "expected an indented class body");
    while (!check(T_DEDENT) && !check(T_EOF) && !had_error) {
        consume(T_DEF, "class body may only contain method definitions");
        consume(T_IDENT, "expected a method name");
        Token m = tk_prev();
        int mk = identConst(m.start, m.len);
        compile_function(m.start, m.len, 0);         /* leaves the method closure on the stack */
        emit2(OP_METHOD, (uint8_t)mk);               /* [.. class closure] -> [.. class] */
    }
    consume(T_DEDENT, "expected the class body to end (dedent)");
    emit(OP_POP);                                    /* pop the working copy of the class */
    (void)has_super;
    current_class = saved;
}
```

```c
        return;
    }
    if (match(T_LBRACKET)) {                       /* indexed target: name[i]...[k] = v */
```

## Notes for the implementer

- **Explicit `self` is the whole simplification.** A method is an ordinary closure; `self` is just its first local. Construction and bound-method calls work by *placing the receiver in slot 0* (the callee slot) and calling the closure with `argc+1`, so the method body reads `self` as local 0 — exactly where the compiler put the `self` parameter. No "this" upvalue, no per-method machinery.
- **`OP_GET_ATTR` is retired, not removed.** Its enum value stays (house rule: never renumber). The compiler stops emitting it; `OP_GET_PROPERTY` subsumes its module-attr behavior. The existing `import`/`fromimport`/`badattr` tests are the regression net — they MUST stay green after Task 3.
- **Method lookup is one dict** thanks to copy-down (`OP_INHERIT`). The `super` pointer exists only for `super.method`. There is no runtime walk up the inheritance chain on a normal `inst.method`.
- **Field-shadows-method order:** `inst.x` and `inst.x(...)` both check `fields` before `methods`, so a callable stored in a field overrides a same-named method. Documented; keep both paths in that order (`OP_GET_PROPERTY` and `OP_INVOKE` instance branch).
- **GC rooting recap (the two house rules in practice):**
  - Constructors `as_class_new` / `as_instance_new` each do 2 `alloc_obj` (object + its dict) before the object is reachable — both wrap in `as_gc_push_disable()/pop_disable()` (like `as_module_new`). `as_bound_method_new` is a single alloc with already-rooted inputs.
  - In the VM: `OP_CLASS` pushes the class as its result before any further op; the `O_CLASS` construct path writes the instance into slot 0 *before* the `init`-name `as_str_copy`; `OP_GET_PROPERTY` keeps `recv` via `peek(0)` across `bind_method`'s alloc; `OP_INVOKE`'s instance fast path holds nothing fresh across an alloc.
  - `as_vm_mark_roots` needs **no change**: classes/instances/bound methods live in module globals, locals (the value stack), or other reachable objects — all already traced.
  - **The `make test-as-gcstress` gate after Tasks 3/4/5 is the verifier.** A stress failure means "a temporary is held across an alloc without being on the value stack" — fix by reordering so the object is on the stack first, never by disabling GC mid-op.
- **Opcodes appended; each task an independent commit; run `make test-as` after each step and `make test-as-gcstress` after Tasks 3, 4, 5.**
- **Verify the `OP_INHERIT` stack order against the compiler's emit order** (Task 4 Step 3 note): the compiler pushes superclass then subclass, so `peek(1)`=super, `peek(0)`=sub. If you change `class_declaration`'s emit order, update the peeks to match.
