## 已写入并接到页面与 Worker 的功能

- `ReadableStream` 的可读、关闭、错误状态；关闭请求等待队列排空；异步 `start/pull`、防止重叠拉取、策略高水位和自定义 `size`。
- `ReadableStreamDefaultReader/Controller`，读锁、挂起读取、`closed`、释放锁和等待底层 `cancel` 完成。
- `ReadableStream.from()` 对同步与异步 iterable 的消费；异步 `values({preventCancel})` 及真实 `Symbol.asyncIterator`。
- `tee()` 两个消费者的需求与取消；两个分支均取消时向原流传递组合原因。
- `WritableStreamDefaultWriter/Controller`，异步写入串行队列、`ready/closed/desiredSize`、关闭、失败、取消和 writer 生命周期；controller 的真实 AbortSignal。
- `pipeTo/pipeThrough` 的 `preventClose/preventAbort/preventCancel/signal`，两端故障传播、等待已交付写入、结束时释放锁。
- `TransformStreamDefaultController` 和双向背压、`start/transform/flush`、关闭、错误与终止。
- `TextEncoderStream/TextDecoderStream`，分段 UTF-8 编码的高代理项保留、增量解码与结束刷新。
- `CountQueuingStrategy/ByteLengthQueuingStrategy` 的高水位及共享 size 函数。
- Fetch Body 的真实 disturbed 状态、直接 reader 消费后的二次消费拒绝、锁定正文拒绝、消费结束释放 reader，以及私有网络字节计数。

## 文件与接线

实现分别在 `c/apps/gui/browser/js/streams/core.c`、`readable.c`、`writable.c`、`transform.c`，各有对应 `.h`。原 `fetch_body_prelude.inc` 的整段 Streams 实现已移除；新增功能没有引入 `.inc` 或第三方依赖。

`webapi.c` 的页面与 Worker 安装流程都先创建取消服务，再安装 Streams。编码器安装后，通过私有 hook 安装文本流。`BROWSER_WEBAPI_SRC` 从浏览器 JS 源清单派生 Streams 文件，避免窄 host 链接遗漏真实产品依赖。

队列使用头索引，消费后立即释放原元素引用，定期压缩存储。这样避免每次 `Array.shift()` 移动剩余元素，也避免用头索引却一直保留大块缓冲区引用。**尚无本批 guest 性能测量，不发布速度提升数值。**

## 保留的边界与最后的验收

Byte-oriented streams、BYOB 尚未实现，相应入口明确拒绝；需要实现缓冲区转移和所有权后才能开放。可转移 Streams 也未实现，本批没有改变消息克隆服务，不声称 transfer 正确。当前没有把默认流伪装成字节流。

最后的联合验证需覆盖实际编译和磁盘打包、stream/Fetch/Worker 回归、队列与背压的故障控制、真实 guest 文本管道与网络消费者、取消后的下一次网络请求。此前 guest 取消样例曾有间歇建连失败；保留 socket ABI 错误码诊断，不能因窄 host 检查通过而宣布该问题消失。

设计依据为 [WHATWG Streams](https://streams.spec.whatwg.org/)、[Fetch Body](https://fetch.spec.whatwg.org/#body-mixin) 和 [DOM cancellation](https://dom.spec.whatwg.org/#aborting-ongoing-activities)。实现为本项目手写代码。
