# AetherScript A1 → A2：仓库迁移

## 范围与版本

仓库原有的 70 个 VM 源码已明确声明 `# aether: 2`：17 个标准库/自举模块、42 个示例、Studio demo、嵌入自举桥、2 个测试驱动和 7 个预览测试脚本。另增加一个 A2 迁移回归程序。10 个原生 A3 源码继续使用 3/3.0。

过去“无声明源码使用 A1”的规则已取消。现在无声明源码按 A2 执行；现有单元测试仍有意覆盖这个默认入口。A1 声明和格式 5 字节码只出现在拒绝测试中。源码版本和字节码格式是两个编号：A2 产物为 `LAQ1`、格式 6、策略 2。

本次是 **A1 到 A2** 的迁移。A2 到 3.x 的静态语言迁移仍未完成，不能删除 A2 VM、自举编译器或它的标准库。

## 行为迁移

| 部分 | A2 下的处理 |
| --- | --- |
| `bits.bit/mask/rol/ror` | 位模式运算显式使用 `wrapping_shl/sub`，包括符号位、63 位掩码和 64 位旋转；负旋转量归一化 |
| 系统调用参数打包 | 生成器对占到第 63 位的字段生成显式回绕；`futex` 参数更名为 `word`，避免遮蔽 `addr()`；调用位置和内核 ABI 不变 |
| `mean/median/moving_average` | 在加法前进入浮点运算，避免合法输入的整数中间和溢出 |
| 插值和距离 | 在端点相减、平方之前转换为浮点；不等待整数溢出后隐式提升 |
| `powi` | 正整数幂保持检查；负幂从开始就用浮点，用平方求幂避免巨大线性循环，不对最小负指数取正 |
| `fib/isqrt/lcm/is_prime/align_up` | 避免仅中间步骤溢出：不多算一个 Fibonacci 数、除法先约分、用商比较代替平方、先计算对齐增量 |
| 精确整数 API | `fact/sum/product/sq` 等的真实整数结果超出 i64 时继续报错，不以浮点近似冒充精确结果 |
| 随机数状态 | 已有乘加范围可容纳于 i64，保留算法和确定性序列；不改成浮点状态 |

浮点 API 仍受现有浮点精度和近似算法限制；这次迁移没有承诺新的高精度数学库。

## 编译、缓存与基准

迁移检查逐个编译所有 A2 源码，比较 C 编译器和自举编译器的完整字节码，再校验格式 6/策略 2。运行阶段只保留新构建的库缓存，移除测试目录中的库源码，确认导入不会偷偷回退到源码。

旧 `bcstable.sha256` 基于 A1 格式 5，迁移时曾明确报红。检查结果为：10 个库只改变文件头；`abi/asc/aslex/bits/math/mathx/stats` 的函数体还包含生成器、诊断/自举和本次数值迁移修正。通过独立行为测试及两套编译器对比后，基准更新为 A2。以后无意改变 A2 字节码仍会报错。

构建产物重新生成，不把旧 `.la` 的版本数字改成 2。历史测试目录和磁盘保留为原始证据；正常磁盘构建会从当前源码生成新的 A2 库。磁盘里的用户工程不在仓库源码清单中，本次没有批量改写它们。

## 验收入口

```sh
make BUILD=build-as-typed test-as-migration
make BUILD=build-as-typed test-as-migration-guest
make BUILD=build-as-typed test-selfhost test-as-bcstable test-as-numeric
```

- `test-as-migration` 已接入 `test-as-fast`。前置负对照恢复 A1 声明、撤销符号位显式回绕，必须观察到对应失败。
- 宿主检查记录源码和产物 SHA-256、两套编译器一致性，以及迁移程序和 11 个可移植示例的源码/缓存执行结果。
- 来宾在独立磁盘中安装新的 `/bin/as` 和 A2 库缓存，执行上述程序，并检查原始指针、文件读写、进程启动、管道和资源释放示例。同时实际验证 A1 源码/缓存拒绝。
- 产物与日志在 `$(BUILD)/a2-migration-时间戳` 及其 `-guest` 目录。宿主和来宾报告均须 `passed: true`、`complete: true`。

GUI、存储崩溃、OOM、调试器等需要专门场景的脚本在本门禁中完成双编译器迁移检查；本门禁不盲目执行这些程序，也不把编译通过称为其全部运行场景已验收。
