# WPT subtests that fail today, as "<path>::<subtest name>".
#
# "<path>::*" means EVERY subtest in that file fails -- the file is
# collapsed to one line because a per-subtest list of an all-red file
# carries no information a single line does not, and the uncollapsed
# form of this corpus is a 16 MB file nobody diffs. Files with a MIXED
# result keep their exact per-subtest entries, which is where a ratchet
# earns its keep: a regression there names the subtest.
#
# "::[HARNESS]" means the file never completed the harness at all -- a
# worse category than a failing assertion, and the one to read first.
#
# A subtest name may contain a newline (css/css-syntax names cases after
# the declaration block under test); those are escaped as \n here and
# unescaped on read, so one entry is always exactly one line.
#
# Regenerate with `make wpt-baseline`. Shrinking this file is the point;
# growing it needs a reason written next to the new entries.
