# Preview application icon

Original raster PNG generated with the built-in imagegen tool. Packaged as
`/icons/preview.png`; consumed by the generic app-icon loader in Dock, Finder
and Preview's library header. Alpha is preserved without post-processing.

The original glossy icon was replaced at the user's request with a flat,
simplified landscape mark. The earlier runtime screenshot in
`build-preview/icon-check/00-list.png` shows the superseded glossy artwork.

Source SHA-256: `666fcac26f27118b58a77ce389d35236ffe25b2532689b51bc691611354f3b19`.

## Generation prompt

Generate a finished FLAT MINIMAL raster app icon for Preview, a desktop image and media viewer. Square 1024x1024, real transparent alpha outside a rounded-square tile occupying 90% of canvas with equal margins. Tile is a single solid muted periwinkle blue, no gradient. Center a simple upright ivory photograph frame with generous border and rounded corners. Inside the photo, flat pale sky blue, one bold teal mountain silhouette made of only two broad peaks, and one small warm yellow circular sun. The composition must use only five solid colors and big simple shapes, extremely clean, instantly readable at 24 pixels. Precise 2D geometry with antialiased edges. No magnifying glass, no tilt, no second photograph, no small details, no outlines around tile, no depth, no bevel, no texture, no reflections, no gloss, no lighting, no drop shadow, no text, no letters, no emoji, no mockup. Produce a single polished flat-design app icon PNG with genuine transparent background and corners.
