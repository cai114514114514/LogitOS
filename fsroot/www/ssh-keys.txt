LogitOS SSH 密钥与文件传输指南（2026-09-13）

支持的个人登录公钥：
- Ed25519
- ECDSA P-256、P-384、P-521
- RSA 2048 至 4096 位，使用 SHA-256 或 SHA-512 签名

以下示例假设账户为 alice，宿主机 2222 端口映射到 LogitOS 的 22。
请按自己的账户和端口修改。服务器的主机身份仍是持久化 Ed25519。

1. 在自己的电脑生成个人密钥（使用标准 OpenSSH ssh-keygen）：

ssh-keygen -t ecdsa -b 384 -f ~/.ssh/logitos_ecdsa

也可以选择 RSA：

ssh-keygen -t rsa -b 3072 -f ~/.ssh/logitos_rsa

按提示设置私钥口令。私钥留在自己的电脑，只把对应 .pub 公钥交给管理员。
RSA 公钥文件开头仍是 ssh-rsa；登录时会协商 SHA-2，无需改写公钥内容。

2. 把公钥加入 LogitOS 账户。

已有可用 SSH 登录时，可以通过 SFTP 把 .pub 上传到自己的 home。
例如连接后执行：

put /本机公钥文件路径/logitos_ecdsa.pub /home/alice/logitos_new.pub

管理员在 LogitOS 控制台创建 /home/alice/.ssh（如尚不存在），然后执行：

cat /home/alice/logitos_new.pub >> /home/alice/.ssh/authorized_keys
stat -c 700 /home/alice/.ssh
stat -c 600 /home/alice/.ssh/authorized_keys

authorized_keys 每行一把完整的 OpenSSH 公钥，可以带注释。
文件最多 16 KiB，所有者应为 root 或此账户。暂不支持带 restrict、command=
等选项的授权行，也不支持 SSH 证书、硬件安全密钥或 DSA。

3. 在自己的电脑登录或传文件：

ssh -p 2222 -i ~/.ssh/logitos_ecdsa alice@127.0.0.1
sftp -P 2222 -i ~/.ssh/logitos_ecdsa alice@127.0.0.1

首次连接应核对管理员通过可信渠道提供的服务器主机指纹。
SFTP 可用 put/get/reget、ls/mkdir、chmod、rename/rm/rmdir，以及：

ln -s report.txt report-link.txt
ln report.txt report-hard.txt
get report-link.txt

相对软链接的目标从链接所在目录解析；硬链接在原文件名删除后仍保留数据。
put -p 所需的时间戳写入、原子独占创建和完整 POSIX 作业控制仍未实现。

浏览器下载到 LogitOS 的文件统一保存在 /download。
SFTP 则使用你在 put/get 命令中指定的路径，默认远程目录为账户 home。
