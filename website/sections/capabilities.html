阅读能力说明 ↗

LOGITFS

让文件留在下一次启动

日志、写入屏障与文件系统检查，共同支撑文件存储。Project 专用磁盘进一步探索改名、移动后的任务关联。

持久身份使用独立 Project 启动路径

TEXT & INPUT

让中文成为日常输入

中文字体、抗锯齿文字与拼音候选进入原生桌面。字体回退与文字排版，也由系统自己的绘制路径处理。

Shift + Space 切换拼音输入

MEDIA

看见画面，听见声音

从图片解析到音视频解码，再连接容器、播放时钟与输出设备，逐步构建完整的媒体路径。

格式与网站播放兼容性按具体样例验证

NETWORK

连接桌面之外

项目维护自己的网络协议栈。HTTP、HTTPS 与浏览器围绕真实页面和互操作测试持续完善。

选定站点可用不等于完整 Web 标准兼容

PROCESSES & MEMORY

让程序各自运行

进程、管道、虚拟内存、页缓存与回收机制，支撑终端和原生应用。宽地址空间与程序装载也在持续推进。

不承诺直接运行 Linux 或 Windows 软件

DEVICES

向真实设备逐步靠近

存储、网络、显示、键鼠与音频驱动分别接入系统。支持范围沿着具体设备、真实输出与验收记录展开。

模拟设备通过，不推导实体硬件已支持
