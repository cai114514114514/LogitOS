在一次原生流程验证中，我们从 Finder 提交资料处理任务，再到 TextEdit 中继续修改、审阅并应用结果。以下是这次验证实际覆盖的内容。

这次实际检查了什么

  • 普通 make run 启动路径能够启动模型任务服务。
  • Finder 原生输入框能够提交任务；所有相关模型请求到达真实 DeepSeek 服务。
  • 报告保留资料中的事实和引用，并按原始字节保存；源资料保持不变。
  • TextEdit 原生输入框能够生成可审阅的修改候选。
  • TextEdit 的 Apply 操作保存确切的候选内容。
  • 会话只使用一个网关，已有文档在会话准备过程中保留。

这次验证的范围

本次使用准备好的测试磁盘与样例资料，运行 BIOS、512 MiB 的 QEMU 配置。为使用该磁盘，验收绕过了完整系统重新打包；它验证的是会话启动与 Finder / TextEdit 原生任务通路。

本次没有重新验证 UEFI、完整文件系统、广泛内存配置或硬件驱动矩阵，也不代表所有任务均能自主完成。使用模型任务仍需配置可用的模型服务。
